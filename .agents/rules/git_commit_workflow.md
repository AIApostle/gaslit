# Mandatory Git Commit Rule

Always commit every change, fix, feature, or rule update to git immediately after verification.

## Execution Rules
1. Every successful task or modification step must end with `git add -A && git commit -m "<descriptive message>"`.
2. Do not leave uncommitted changes or unstaged files in the workspace.
3. Keep `.gitignore` updated to prevent committing build artifacts, virtual environments, or credentials.
