# UI & Design Taste Guidelines

## UI Principles
1. **Preserve What Works**:
   - The user explicitly likes the current UI (the dark-accented topbar, HC brand mark, primary tab navigation, and split-screen workspace).
   - Do NOT tear down or rewrite the existing layout. Refine it, add the missing capabilities, and seamlessly integrate SwiftAgents.
2. **SwiftAgents Integration**:
   - Make SwiftAgents the flagship conversational intake: provide clear, prominent trigger buttons (`"Report via AI Grievance Officer"`) and floating launchers.
   - Support in-browser chat as the primary channel.
3. **Anti-Slop Discipline**:
   - Avoid generic AI card bloat and distracting animations.
   - Maintain crisp typographic contrast, clean semantic badges, and clear status indicators.
   - Ensure all interactive elements are responsive and have comfortable touch targets (minimum 44px).
